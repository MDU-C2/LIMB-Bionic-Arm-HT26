# Data

`legacy/limb1/training/` contains the 100 camera movement recordings inherited
from LIMB1, with 20 recordings from each of five participants.

New subject recordings go in `outputs/recordings/`, which is ignored by Git.
Keep subject IDs instead of names. See the [recording guide](../docs/RECORDING_GUIDE.md)
and [movement training](../src/ml/README.md) for their different file formats.
