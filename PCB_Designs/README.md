# PCB Designs – AURORA HT26

## Overview

This directory contains the PCB designs developed and used in the AURORA project. The boards are designed to support the robotic arm's motor control, sensor acquisition, and communication systems.

Each PCB project contains the necessary design and manufacturing files, including:

- **Schematic** – Electrical circuit design.
- **PCB Layout** – Physical component placement and routing.
- **Footprint Library** – Custom component footprints.
- **BOM (Bill of Materials)** – List of required components.
- **Gerber & Drill Files** – Files required for PCB manufacturing.

The designs are developed using **KiCad 10** and **National Instrument Multisim/Ultiboard**.

---

## PCB Modules

### 1. Biceps_Module

This PCB controls the motors responsible for movement of the biceps/lower arm using X and Y control inputs.
The module communicates with the other robotic arm controllers through the CAN bus.
- **CAN Node:** 2 of 4
- **CAN Position:** Between Shoulder (Node 1) and Hand_Motor (Node 3)
- **CAN Termination:** Not required

### 2. CAN_Transceiver

This PCB is a custom CAN transceiver board designed to enable CAN communication between the Jetson AGX Orin and the robotic arm's motor controllers.
The design is based on the [Waveshare SN65HVD230 CAN Board](https://www.waveshare.com/sn65hvd230-can-board.htm).
To reduce dependency on external component delivery times, the project group developed a custom version that could be manufactured and assembled in-house.
The same PCB design can be used throughout the CAN network.

**Important – CAN Bus Termination**
A 120 Ω termination resistor must only be installed at the two physical ends of the CAN bus.
| CAN Transceiver Location | 120 Ω Resistor |
|---|---|
| Jetson AGX Orin → Shoulder (bus start) | Installed |
| Shoulder | Not Installed |
| Biceps_Module | Not installed |
| Hand_Motor | Not installed |
| Hand_Pressure (bus end) | Installed |

Incorrect termination may lead to signal reflections, communication errors, and unstable CAN operation.

### 3. Hand_Motor

This PCB controls the motors responsible for hand movement.
It receives control commands through the CAN bus and operates as the third node in the robotic arm's communication network.
- **CAN Node:** 3 of 4
- **CAN Position:** Between Biceps_Module and Hand_Pressure
- **CAN Termination:** Not required

### 4. Hand_Pressure

This PCB is responsible for acquiring pressure measurements from the robotic hand during object grasping.
The collected sensor data can be used to monitor contact pressure and support grip control.
- **CAN Node:** 4 of 4
- **CAN Position:** Final node on the CAN bus
- **CAN Termination:** Required (120 Ω)
The CAN transceiver connected to this module must have its termination resistor installed.

### 5. Human_Sensor

This PCB is designed for the acquisition, amplification, and filtering of electromyography (EMG) signals.
The analog signal-conditioning circuit amplifies the small electrical signals generated by muscle activity and filters unwanted noise before the signals are acquired by the microcontroller.

The intended output characteristics are:
- **Resting state: Approximately 1.5 V DC output.
- **Signal noise: Low peak-to-peak voltage during rest.
- **Muscle activation: Changes in the output signal corresponding to measured muscle activity.

The PCB also provides mounting positions for:
- **ESP32-C3 – Microcontroller for data acquisition and communication.
- **IMU – Inertial Measurement Unit for motion sensing.

The Human_Sensor PCB is part of the user-worn sensing system and is separate from the robotic arm's CAN motor-controller network.

Notes
The custom CAN transceiver PCB is designed for reuse across multiple robotic arm modules.
CAN termination must be configured according to the physical bus topology.
Custom KiCad footprints are stored in the corresponding project libraries to simplify project sharing.
PCB designs should be verified before manufacturing or assembly.
