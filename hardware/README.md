# Hardware

This directory is reserved for the verified source of truth for the physical
AURORA arm. It does not yet contain an as-built hardware package.

The next hardware handover should include:

- an as-built bill of materials with board and actuator revisions;
- wiring, connector, power, protection, and emergency-stop diagrams;
- measured joint zero positions, travel, speed, mass, and inertia;
- editable PCB, schematic, and selected CAD sources; and
- dated repair, calibration, and condition notes.

The meshes below `src/simulation` are runtime assets. They do not replace the
canonical CAD or prove the dimensions of the current arm.
